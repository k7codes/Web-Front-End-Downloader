# Web Frontend Downloader

A simple tool for downloading website frontend resources.

## Features
- Download website frontend files
- Extract HTML, CSS and JavaScript
- Simple and easy-to-use interface
- Fast and lightweight

## Usage
1. Enter the website URL.
2. Start the download process.
3. Save the extracted frontend files.

## Disclaimer
This project is intended for educational and development purposes. Only download content you have permission to access.
